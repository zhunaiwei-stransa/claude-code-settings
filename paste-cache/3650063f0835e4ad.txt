  3. Missing input validation — c.Bind instead of echoapi.BindAndValidate

  create_sentence_template_handler.go:34:
  if err := c.Bind(&input); err != nil {

  All other outpatient handlers (patch_reservation_handler.go:37, cancel_reservations_handler.go:45, update_reservation_status_handler.go:43) use echoapi.BindAndValidate(). Plain c.Bind skips struct validation tags entirely.

  Currently the CreateSentenceTemplateInput.Content field has no validate tag at all — so an empty string passes through binding, only to be caught later by sentencetemplatevo.NewSentence() in the domain factory. While the
  domain catches it, using BindAndValidate with a validate:"required" tag would be consistent with the codebase pattern and provide clearer error messages.
